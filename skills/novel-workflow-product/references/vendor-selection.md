# Vendor Selection

- `xyflow/vite-react-flow-template`: MIT, lightweight, good for a clean React Flow base.
- `synergycodes/workflowbuilder`: preferred richer workflow editor candidate; retry vendoring when network permits.
- `JoshuaC215/agent-service-toolkit`: MIT, useful FastAPI/LangGraph service reference; extract patterns, not the heavy stack.
- Dify, Flowise, Langflow, and n8n are reference products unless license and weight are explicitly accepted.
